同频 SAME VIBE - 多轮联想修复版

本次修复内容
1. 每局开始时从题库随机选择一道开场题（同词联想和默契问答各有题库）。
2. 所有当前玩家提交后，服务器自动揭晓并记录本轮问题、玩家和答案。
3. 如果答案不完全一致，房主可点击“进入下一轮”；新问题会包含上一轮所有玩家的答案作为联想起点，不再重置为夏天题。
4. 全员答案一致时，自动结束本局并显示成功提示。
5. 最多进行 12 轮；第 12 轮仍未一致时结束本局。
6. 结束后显示所有轮次的问题、玩家答案和每轮结果。
7. 保留房间、2-8 人、玩家刷新恢复、断线宽限时间等原有机制。

更新方式（Windows）
1. 先把当前 E:\sameword-8 文件夹复制一份作为备份。
2. 将此 ZIP 解压到 E:\ 目录，允许覆盖同名文件。ZIP 内不包含 node_modules，因此不会覆盖现有依赖。
3. 保持运行 Vite 的 PowerShell 窗口不动；它通常会自动热更新前端。
4. 在运行 node server.mjs 的后端窗口按 Ctrl+C 停止旧服务，然后运行：
   cd E:\sameword-8
   node server.mjs
5. 等待显示“Same Vibe 联机服务器已启动：http://0.0.0.0:3001”，再刷新电脑和手机页面。

注意
- 只在运行 node server.mjs 的后端窗口按 Ctrl+C，不要关闭运行 Vite 的前端窗口。
- 后端多轮流程已通过两名模拟玩家的联机事件测试：不同答案自动揭晓、下一轮带入上一轮答案、答案一致后结束并保存回顾。
- 当前打包环境无法执行 Vite build，因为上传压缩包里的 node_modules 是 Windows 原生依赖，而验证环境为 Linux；没有把这个说成已通过的浏览器构建测试。
